## 👨‍💻 O mnie

Po 5 latach w operacjach IT i security (NOC, SOC, Security Engineer) świadomie zmieniam ścieżkę w stronę DevOps.  
Buduję praktyczne umiejętności w Python, Docker, Git, AWS, Linux, a efekty dokumentuję na tej stronie.

## 🧪 Projekty własne

- **AI Notes Pipeline** – system generowania notatek z AI, weryfikacja, publikacja przez GitHub Pages.
- **Docker labs** – budowanie obrazów, docker-compose (w toku).
- **Python scripts** – automatyzacja, OOP, praca z danymi.

## 🌐 Baza wiedzy DevOps

Wszystkie notatki techniczne są dostępne na stronie głównej – każda to case study z konkretnego problemu (np. Git disaster recovery, SSH config, rebase).

## 🔁 Workflow pracy

1. Generowanie notatki przez AI (na podstawie promptów).
2. Ręczna weryfikacja i uzupełnienie braków.
3. Zapis jako `.md` w `_posts/`.
4. Commit + push → GitHub Pages automatycznie publikuje.

## 🧠 Wykorzystanie AI

AI wspiera mnie w nauce – generuje szkice notatek, ćwiczenia, tłumaczy złożone zagadnienia.  
Nie zastępuje myślenia, ale przyspiesza dokumentację i porządkuje wiedzę.
